ゴースト「アスタロト」 v2
========================

SSP用のアスタロト専用ゴースト。SHIORIはYAYA。
v2 で相方フルフルが加わり、二人構成になった。

登場人物:
- アスタロト（\0）: 地獄の大公爵／堕天使。ソロモン72柱の29番目（当人の設定）、
  40の軍団を従える。ユーザーのことは「貴方」と呼ぶ。
- フルフル（\1）: 雷と愛を司る堕天使。元気で気まぐれ。
  ユーザーのことは「マスター」と呼ぶ。アスタロトのことは普段「アスタロト」、
  茶化す時だけ「ロトちゃん」。
  ※自己紹介で「72柱の26番目」と言うが、原典では34番目で26は軍団数。
    初回起動トークのネタとして使っている。

v2の内容:
- シェル: アスタロト surface0〜5（通常＋表情5種）、
  フルフル surface10〜15（通常＋表情5種、seed1031で統一、全て835×1216）
- 辞書: 初回起動（フルフルの自己紹介あり）／通常起動3種／終了2種を二人版に改訂
- ランダムトーク44本（掛け合い24／アスタロト独白10／フルフル独白10）。
  間隔は420秒（7分）、直前と同じ台詞の連続選出を避ける設定つき
- 声つき時報（毎正時、MP3 24本）と SSTP 音声（OnAstarothSay）は v1 から継続

テスト用フック:
- OnAstarothHourlyTest: Reference0 に時（0〜23）でその時刻の時報を即時再生
- OnFurfurTalkTest: ランダムトークを1本即時再生（間隔待ちなし）

サーフェス番号の予約:
  0〜5 = アスタロト（実装済み）／ 6以降 = アスタロトのポーズ差分
  10〜15 = フルフル（実装済み）／ 16以降 = フルフルの差分
  将来、衣装違いの別シェル（フルフルのリボン衣装など）を追加する構想がある。
