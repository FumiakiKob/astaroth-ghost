# アスタロト SSPゴースト v1

irodori-TTS自動再生の受け先となる、SSP用アスタロト専用ゴーストの成果物置き場。

- `astaroth.nar` — SSPへドラッグ＆ドロップで導入するゴースト本体（導入手順と未検証事項は `REPORT.md` 参照）
- `surface0.png` — シェルの立ち絵（透明PNG、478×1216）
- `src_images/` — 生成元絵3枚（採用 seed20261101、次点 seed1101、不採用 seed777001）
- `REPORT.md` — 制作レポート（プロンプト/シード、透明化手法、SSTP到達性の結果、残課題）
- `build/astaroth/` — .nar の中身（展開済みソース）
- `work/` — 生成・解析・キーイングのスクリプト

v1は立ち絵1枚＋YAYA最小辞書（起動・終了のみ）。表情・ポーズ差分はサーフェス番号を予約済みで、後から追加する。
